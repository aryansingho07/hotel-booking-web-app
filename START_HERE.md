# 🏨 START HERE - Hotel Booking Web App

## ⚡ Quick Start (Copy & Paste)

Open your terminal in this directory and run:

```bash
npm install && cd client && npm install && cd .. && npm run dev
```

Wait for both servers to start, then open: **http://localhost:3000**

## ✅ What's Been Built

This is a **complete hotel booking application** with:

### Frontend (React)
- Landing page with hotel listings
- Hotel details page with rooms
- Booking form with validation
- Admin dashboard
- Responsive Bootstrap design

### Backend (Express + MongoDB)
- RESTful API
- Hotel and Booking models
- CRUD operations
- Dummy data included

### Features
✅ Search hotels by city
✅ View hotel details and rooms
✅ Book rooms with date validation
✅ Admin page to manage bookings
✅ Responsive design
✅ Works with or without MongoDB
